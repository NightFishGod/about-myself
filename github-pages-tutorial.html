30 分钟把你的个人网站弄上线

零成本、纯静态、自动部署。不需要买服务器、不用配 Nginx，一个 GitHub 账号 + 一个浏览器就够了。

⏰ 约 30 分钟 📚 6 个步骤 💻 新手友好 🚀 即时生效
准备

开始之前，你需要这些东西

✓ 一个写好的网站文件夹（至少有一个 index.html 作为首页）
✓ 能够上网的电脑
✓ 一个邮箱（用来注册 GitHub）
✓ 30 分钟的耐心
提示：如果你还没有网站文件，先做一个最简单的 index.html，里面哪怕只写一句"Hello World"都行。本文用纯手动 Git 命令部署，不用 GitHub Desktop，确保你在任何电脑上都能操作。
第 1 步

注册 GitHub 账号

打开 github.com，点击右上角 Sign up。

关于用户名：取一个你满意的英文用户名，它将成为你网站的域名的一部分。例如用户名是 zhangsan，你的网站域名就是 zhangsan.github.io。
第 2 步

创建一个特殊的仓库

登录后，右上角点 + → New repository。

关键规则：仓库名必须是 你的用户名.github.io，一字不差，GitHub 才会自动把它识别为个人网站。另外必须选 Public（公开），否则 Pages 功能要付费。

创建完成后你会进入一个空仓库页面，上面写着几条命令。别管这些，我们进入下一步。

第 3 步

把网站文件推送到 GitHub

这一步是目前最有技术含量的环节，但把它看懂就一通百通了。

3.1 安装 Git（如果还没有）

打开 git-scm.com 下载安装包，一路点 Next 安装即可。打开 PowerShell（开始菜单搜 PowerShell），输入以下命令验证：

PS> git --version
# 应该输出类似：git version 2.44.0

3.2 告诉 Git 你是谁（只做一次）

PS> git config --global user.name "你的名字"
PS> git config --global user.email "你的邮箱@example.com"

3.3 进入你的网站文件夹，执行以下命令

假设你的网站文件夹在 D:\my-website\（改成你自己的路径）：

PS> cd D:\my-website
# 1. 初始化 Git 仓库
PS> git init
# 2. 把所有文件加入暂存区
PS> git add -A
# 3. 提交到本地仓库
PS> git commit -m "第一次提交：上线个人网站"
# 4. 关联远程仓库（把 zhangsan 换成你的用户名）
PS> git remote add origin https://github.com/zhangsan/zhangsan.github.io.git
# 5. 推送到 GitHub
PS> git push -u origin main
弹出登录框：push 之后 GitHub 会弹出一个浏览器窗口让你登录授权，点击授权即可。如果没弹窗，试试执行 git push -u origin main 之后再试。
以后怎么更新？改完文件后只需执行 3 条命令：git add -A → git commit -m "描述改了啥" → git push
第 4 步

开启 GitHub Pages 部署

回到仓库页面，点击顶部的 Settings 标签 → 左侧菜单找到 Pages。

在 Branch 下拉菜单里选 main，目录选 / (root)，然后点 Save。等几秒到一分钟，GitHub 会自动构建，亮起绿灯就上线了。

如果默认分支不是 main：有些旧账号默认分支叫 master，选对应的即可。不确定的话，在仓库页面上方可以看到分支名。
第 5 步

打开你的网站，确认一切正常

浏览器里输入 https://你的用户名.github.io/

Welcome to my personal website
等了几分钟还是看不到？
  • 检查仓库名是否正确：必须是 用户名.github.io（大小写也一致）
  • 打开 Settings → Pages 看看是不是显示绿色对勾
  • 确认 index.html 在仓库的根目录，不是子文件夹里
  • 浏览器按 Ctrl+Shift+R 强制刷新
  • 等等 — 首次部署偶尔需要 5-10 分钟
进阶

你已经掌握了核心流程。接下来可以做什么？

✓ 绑定自定义域名：在 Settings → Pages → Custom domain 填上你自己的域名，再到 DNS 服务商添加一条 CNAME 记录指向 你的用户名.github.io
✓ 每次更新网站：改完文件 → git add -A && git commit -m "更新" && git push，1 分钟内自动上线
✓ 用 AI 写网站：不会手写 HTML 没关系，告诉 AI「帮我写一个响应式个人主页，深色风格，包含项目展示和时间线」，直接拿到代码
速查

Git 命令速查卡

日常更新只需要下面几条命令，全部在 PowerShell 中你的项目文件夹下执行。

命令 作用
git add -A 把所有改动加入暂存区（新建、修改、删除都包括）
git commit -m "说明" 提交到本地仓库，附上改动说明（用中文写，自己能看懂就行）
git push 推送到 GitHub，网站自动更新
git status 查看当前有哪些文件被改动了
git log --oneline 查看提交历史记录
